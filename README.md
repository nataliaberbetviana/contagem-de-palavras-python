# Contador de Palavras em Python

## Descrição do Projeto

Este é um projeto simples em Python com o objetivo de demonstrar habilidades fundamentais de programação. O script lê o conteúdo de um arquivo de texto, conta o número de palavras e salva o resultado em um novo arquivo.

O projeto é parte da minha jornada de aprendizado e serve para praticar conceitos básicos de manipulação de arquivos e lógica de programação.

## Funcionalidades

* Lê o conteúdo de um arquivo de texto (entrada.txt).
* Processa o texto para contar o número exato de palavras.
* Salva o resultado da contagem em um novo arquivo (resultado.txt).

## Como Usar

### Pré-requisitos
* Python 3.x
* Git

## Passo a Passo
* Clone o repositório:
  ```
  git clone git@github.com:nataliaberbetviana/contagem-de-palavras-python.git
  ```
* Crie o arquivo de entrada:
Crie um arquivo chamado entrada.txt na pasta do projeto e adicione o texto que você deseja contar.

* Execute o script:
  ```
  python contar_palavras.py
  ``` 
* Verifique o resultado:
Um novo arquivo chamado resultado.txt será criado com a contagem de palavras.
